# Theme Factory Skill（主题工厂技能）

本技能提供一套精选的专业字体与配色主题集合，每个主题都包含精心挑选的调色板和字体搭配。选定主题后，可将其应用于任何产出物。

## 用途

本技能用于为演示幻灯片等产出物应用统一、专业的样式。每个主题包含：
- 一套协调的调色板（含十六进制色值）
- 标题与正文的互补字体搭配
- 独特的视觉风格，适用于不同的场景和受众

## 使用说明

为幻灯片或其他产出物应用样式的步骤：

1. **展示主题预览**：向用户展示 `theme-showcase.pdf` 文件，以便他们直观地查看所有可用主题。不要对其进行任何修改，只需展示文件供用户浏览。
2. **询问用户选择**：询问用户要将哪个主题应用于幻灯片
3. **等待用户确认**：获取用户对所选主题的明确确认
4. **应用主题**：选定主题后，将所选主题的配色和字体应用到幻灯片/产出物中

## 可用主题

共有 10 个可用主题，每个主题均在 `theme-showcase.pdf` 中展示：

1. **Ocean Depths**（深海之境） - 专业而沉静的海洋主题
2. **Sunset Boulevard**（日落大道） - 温暖而充满活力的日落色调
3. **Forest Canopy**（林间树冠） - 自然沉稳的大地色调
4. **Modern Minimalist**（现代极简） - 简洁时尚的灰度配色
5. **Golden Hour**（黄金时刻） - 浓郁温暖的秋日色调
6. **Arctic Frost**（极地霜霜） - 清冷爽利的冬季灵感主题
7. **Desert Rose**（沙漠玫瑰） - 柔和精致的灰粉色调
8. **Tech Innovation**（科技创新） - 大胆现代的科技美学
9. **Botanical Garden**（植物花园） - 清新自然的花园色彩
10. **Midnight Galaxy**（午夜星河） - 戏剧性的宇宙深色调

## 主题详情

每个主题定义在 `themes/` 目录下，包含完整的规格说明：
- 协调的调色板（含十六进制色值）
- 标题与正文的互补字体搭配
- 独特的视觉风格，适用于不同的场景和受众

## 应用流程

选定主题后：
1. 从 `themes/` 目录读取对应的主题文件
2. 在整个幻灯片中统一应用指定的配色和字体
3. 确保足够的对比度和可读性
4. 在所有幻灯片中保持主题的视觉一致性

## 自定义主题
当现有主题均不适用于某个产出物时，可创建自定义主题。根据用户提供的输入，生成与上述主题格式类似的新主题。为主题取一个能描述字体/配色组合含义的名称。利用用户提供的基本描述来选择合适的配色和字体。生成主题后，展示给用户审阅和确认。随后按上述流程应用该主题。
