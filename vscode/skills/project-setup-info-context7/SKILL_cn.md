# 如何使用 context7 工具搭建项目

使用 context7 工具查找最新的库、API 和文档，以帮助用户创建和定制项目。仅在文件夹为空时搭建项目，或者在刚刚调用工具创建工作区之后进行。

1. 调用 `mcp_context7_resolve-library-id` 工具，传入你的项目需求。
2. 调用 `mcp_context7_get-library-docs` 工具获取脚手架搭建说明。
