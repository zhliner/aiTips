# Skill 设计的说服原则

## 概述

LLM 对人类同样的说服原则产生响应。理解这种心理学有助于你设计更有效的 skills——不是为了操纵，而是为了确保关键实践即使在压力下也能被遵循。

**研究基础：** Meincke et al. (2025) 用 N=28,000 次 AI 对话测试了 7 种说服原则。说服技术使合规率翻了一倍多（33% → 72%，p < .001）。

## 七大原则

### 1. 权威
**是什么：** 对专业知识、资质或官方来源的服从。

**在 skills 中的运作方式：**
- 命令式语言："YOU MUST"、"Never"、"Always"
- 不可协商的框架："No exceptions"
- 消除决策疲劳和合理化说辞

**使用时机：**
- 纪律执行类 skills（TDD、验证要求）
- 安全关键实践
- 已确立的最佳实践

**示例：**
```markdown
✅ 在测试之前写了代码？删除它。从头开始。没有例外。
❌ 考虑在可行时先写测试。
```

### 2. 承诺
**是什么：** 与先前的行为、声明或公开宣言保持一致。

**在 skills 中的运作方式：**
- 要求宣告："Announce skill usage"
- 强制明确选择："Choose A, B, or C"
- 使用跟踪：用 todos 做检查清单

**使用时机：**
- 确保 skills 被实际遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 当你找到一个 skill 时，你必须宣告："我正在使用 [Skill 名称]"
❌ 考虑让你的搭档知道你在用哪个 skill。
```

### 3. 稀缺性
**是什么：** 来自时间限制或有限可用性的紧迫感。

**在 skills 中的运作方式：**
- 时间约束的要求："Before proceeding"
- 顺序依赖："Immediately after X"
- 防止拖延

**使用时机：**
- 即时验证要求
- 时间敏感的工作流
- 防止"我稍后再做"

**示例：**
```markdown
✅ 完成任务后，立即请求代码审查再继续。
❌ 你可以在方便时审查代码。
```

### 4. 社会证明
**是什么：** 对他人行为或被视为常态的事物的从众。

**在 skills 中的运作方式：**
- 普遍模式："Every time"、"Always"
- 失败模式："X without Y = failure"
- 建立规范

**使用时机：**
- 记录普遍实践
- 警告常见失败
- 强化标准

**示例：**
```markdown
✅ 没有 todo 跟踪的检查清单 = 步骤会被跳过。每次都是。
❌ 有些人发现 todo 列表对检查清单有帮助。
```

### 5. 统一性
**是什么：** 共同身份、"我们感"、群体归属感。

**在 skills 中的运作方式：**
- 协作语言："our codebase"、"we're colleagues"
- 共同目标："we both want quality"

**使用时机：**
- 协作工作流
- 建立团队文化
- 非层级化实践

**示例：**
```markdown
✅ 我们是共同工作的同事。我需要你诚实的技术判断。
❌ 你大概应该告诉我如果我错了。
```

### 6. 互惠
**是什么：** 回报所受恩惠的义务感。

**运作方式：**
- 谨慎使用——可能感觉像操纵
- skills 中很少需要

**何时避免：**
- 几乎总是如此（其他原则更有效）

### 7. 喜好
**是什么：** 偏好与我们喜欢的人合作。

**运作方式：**
- **不要用于合规**
- 与诚实反馈文化冲突
- 制造谄媚

**何时避免：**
- 纪律执行时始终避免

## 按 Skill 类型的原则组合

| Skill 类型 | 使用 | 避免 |
|------------|-----|-------|
| 纪律执行类 | 权威 + 承诺 + 社会证明 | 喜好、互惠 |
| 指导/技术类 | 适度权威 + 统一性 | 过度权威 |
| 协作类 | 统一性 + 承诺 | 权威、喜好 |
| 参考类 | 仅清晰度 | 所有说服原则 |

## 为什么有效：心理学

**明确的规则减少合理化说辞：**
- "YOU MUST" 消除决策疲劳
- 绝对语言消除"这是例外吗？"的问题
- 明确的反合理化说辞反驳堵上特定漏洞

**执行意图创造自动行为：**
- 清晰的触发器 + 必需的动作 = 自动执行
- "When X, do Y" 比 "generally do Y" 更有效
- 减少合规的认知负荷

**LLM 是拟人的：**
- 在包含这些模式的人类文本上训练
- 权威语言在训练数据中先于合规出现
- 承诺序列（声明 → 行动）被频繁建模
- 社会证明模式（everyone does X）建立规范

## 道德使用

**正当的：**
- 确保关键实践被遵循
- 创建有效的文档
- 防止可预见的失败

**不正当的：**
- 为个人利益操纵
- 制造虚假紧迫感
- 基于内疚的合规

**检验标准：** 如果用户完全理解这种技术，它是否仍服务于用户的真正利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 七大说服原则
- 影响力研究的经验基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 用 N=28,000 次 LLM 对话测试了 7 种原则
- 使用说服技术后合规率从 33% 提高到 72%
- 权威、承诺、稀缺性最有效
- 验证了 LLM 行为的拟人模型

## 快速参考

设计 skill 时，请问：

1. **它是什么类型？**（纪律 vs. 指导 vs. 参考）
2. **我想改变什么行为？**
3. **哪些原则适用？**（纪律通常是权威 + 承诺）
4. **我是否组合了太多？**（不要全部使用七种）
5. **这是否道德？**（服务于用户的真正利益？）
