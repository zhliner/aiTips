# 技术规格（Spec）

由 Conception + Decision 生成的技术规格（Spec）。如模块划分、接口与数据设计、字节编码、字段宽度、实现的规则等。请在必要的精简和足够的细粒度之间保持良好权衡。

文档内容大致遵循如下结构：

- 来源追溯
- 概述
- 规格正文
- 边界与限制
- 待决问题
- 对 Plan 的约束
